# İlk hafta – Git ve GitHub

Başta Git ile GitHub'ı karıştırıyordum. Git, bilgisayarımda yaptığım değişiklikleri kaydediyor. GitHub'da da projeyi paylaşabiliyorum.

## Kısa notlarım

- **Repo** projenin dosyalarını ve geçmişini bir arada tutar.
- **Commit** yaptığım değişikliği kısa bir notla kaydeder.
- **Branch** yeni bir şey denemek için açtığım daldır. **Merge** iki daldaki değişiklikleri birleştirir.
- **Clone** projeyi geçmişiyle birlikte bilgisayarıma kopyalar.
- **Pull** son değişiklikleri bilgisayarıma alır. **Push** kendi commit'lerimi GitHub'a gönderir.
- **.gitignore** geçici dosyalar gibi Git'in takibe almasını istemediğim dosyaları belirtir.

Git sayesinde eski bir sürüme dönebiliyorum. Ekipte herkes kendi dalında çalışabiliyor ama iki kişi aynı satırı değiştirirse birleştirirken o satırı düzeltmek gerekebiliyor. Sürüm takibi için SVN, proje paylaşmak için de GitLab kullanılabiliyor.

## Ne yaptım?

HTML ve CSS ile bir ana sayfa ve iletişim formu hazırladım. JavaScript ile ana sayfadaki butona Git ipuçları ekledim. Formu da denemek için yaptım. Siteyi açmak için proje klasöründeki `index.html` dosyasına çift tıklamak yeterli.

Değişiklikleri tek tek kaydedince hangi adımda ne yaptığımı daha kolay gördüm.
